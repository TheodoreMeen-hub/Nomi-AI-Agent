# Nomi-AI-Agent（新能源汽车售前AI购车决策Agent）
面向直营新能源车企的轻量化售前增长AI工具，不改造原有业务链路，低试错成本验证线索质量提升效果。

# 核心亮点
- 轻量化外接定位，不重构选配/CRM核心链路，试错成本低
- 三级风险管控体系，一级高危问题拦截率100%
- 可信度分级用户画像，解决销售端信任问题
- 五轮完整迭代，覆盖需求→调研→原型→风控→价值全链路
